# Saudi-Audience Company Profile — Research

Date: 2026-09-23
Purpose: benchmark what a company profile must contain to be shared with Saudi-based
companies/enterprises, and list reference profile archetypes. Sources: Labeeb KSA
profile-writing guide, Weoryx (KSA) on profile design in the Saudi market, Arab Dreams
vendor-registration guide (KSA), general IT company profile structure guides, plus the
project's own memory files (FRD, content architecture, antislop rules).

## 1. Benchmark list — company profile types/examples reviewed

1. **M-TECH corporate profile** (the user's stated quality reference) — premium
   corporate-document feel: cover, overview, verticals, capabilities, snapshot, close.
2. **Saudi profile-writing standard (Labeeb KSA)** — Saudi profiles must:
   - be **bilingual EN/AR** (each language builds trust separately; Arabic-first for
     many KSA decision makers),
   - include full **legal identity**: Commercial Registration (CR) number, Chamber of
     Commerce membership, VAT/ZATCA registration, MISA license (if foreign-owned),
     National Address,
   - carry strong **trust signals** and verified facts only.
3. **Weoryx KSA guidance** — in the Saudi market the profile IS the credibility
   artifact before any meeting; premium design + factual precision both matter.
4. **Saudi vendor-registration / Etimad dossiers** — practical profile must supply:
   CR, MISA, VAT, GOSI, Nitaqat (Saudization) status, document checklist, bank details
   (optional), and a track-record section.
5. **Saudi Vision 2030 positioning** — profiles that align services to national
   priorities (food security, agritech, digital transformation, SME digitization)
   outperform generic tech profiles. Next360's agri + IT mix maps naturally.
6. **Standard international IT-company profile structure** (cover → overview →
   services → verticals → selected projects → methodology → quality/security →
   team → technology → clients → contact) — same skeleton the FRD already uses.
7. **TrustMary / US Chamber trust-signal structure** (from earlier memory research):
   concrete facts, named people, verifiable claims, no superlatives.

| S6 | Full contact block: Indian registered office, phone, email, website | absent today |
| S7 | Selected projects with problem → contribution → outcome | FRD content rules; Saudi buyers foreground track record |
| S8 | Certifications section (ISO etc.) + "documents available on request" appendix | slots TBC; speeds contract onboarding |
| S9 | Clients/industries (permission-gated only) | FRD rule: disclose only with permission |
| S10 | Contract/commercial note: billing currency, contracting entity | foreign-contractor clarity; values TBC |

NOT applicable (Saudi-side — do not add): Commercial Registration, MISA license,
Chamber of Commerce membership, ZATCA VAT, National Address, Nitaqat/Saudization.
These belong to the Saudi counterparty, not an Indian contractor.
