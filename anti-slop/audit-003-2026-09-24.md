### 1. Three text pairs below WCAG AA contrast — HIGH (R-25)
Measured, not guessed:
- gold `#A8873F` small text on ivory pages: **3.27:1** (needs 4.5). Affects
  `.section-label .num`, `.stat-label`, `.v-num`, `.p-num`.
- muted `#707770` on ivory pages: **4.45:1** (needs 4.5). Affects `.folio`,
  `.section-label`, `.photo figcaption`, `.step p`, `.eco-item p`.
- cream at 55% on flagship green: **4.11:1** (`.flagship-page .folio`).
Verified passing fixes: gold text `#7A6228` (5.63), muted `#6B726B` (4.78),
folio alpha .65 (5.10). One-token change, no layout impact.

**Approved 2026-09-24 and FIXED.** Applied as token changes: `--gold` ->
`#7A6228`, `--muted` -> `#656C65`, `--gold-soft` -> `#D2B773`, flagship folio
alpha .55 -> .65. While fixing, two more instances of the same failure were
found and included: gold-soft small text on the faint-green card backgrounds
(`.cover-flagship .tag`, `.flag-cap h4`: 4.03:1 -> 4.58:1) and muted text on
the new sage lead card (4.09:1 -> 4.80:1). Re-measured after the change:
11/11 affected pairs now >= 4.5:1 (lowest 4.58), verified by script.

### 2. No DESIGN.md at project root — HIGH (R-37)
Still open from audit-001 #2. The profile's direction lives only in CSS tokens
and code comments, so every future edit re-derives taste from scratch. Fix:
write DESIGN.md (identity, palette, typography, mood, dials). Until then this
file is a *draft without direction* by the letter of the rule.

### 3. All 13 photos are hotlinked from 3 external CDNs — MEDIUM (C-4)
Flickr, StockSnap, Pexels. A deliverable meant to be printed and emailed
depends on strangers' URLs staying alive; StockSnap already returns 403 to
non-browser agents. Fix: download the images into `public/` (or an
`assets/` folder next to the file) and reference locally.

**Approved 2026-09-24 and FIXED.** All 13 photos downloaded to `assets/`
(3.8 MB, all verified JPEG) and all `src` attributes now use relative local
paths; grep confirms 0 external `src="http..."` image references. Verified
with network fully blocked (offline simulation, headless Chrome, 1440 + 390):
13/13 images load from disk, 0 remote image requests, no overflow, print
button works. The only remaining external request is the Google Fonts CSS;
offline the page falls back to the system font stack as designed.
